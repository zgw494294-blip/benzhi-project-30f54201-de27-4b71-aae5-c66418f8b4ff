# 电缆局放诊断放行台

电缆局放诊断放行台面向高压试验工程师、电缆运维负责人和安全复核专家，用一个浏览器工作台完成局放试验的查重建批、多点边界冻结、批量现场采样、可解释规则诊断、偏差整改、定向复验、双人复核与复归放行证书封存。所有业务变更都采用 `expectedVersion` 乐观并发控制和幂等键，并写入带连续序号及 SHA-256 哈希的本地审计链。

## 构建与运行

项目使用 Go 1.22 或更高版本，无需 Node.js 或外部数据库。

```text
go build ./...
go run ./cmd/pdconsole -addr=127.0.0.1:19081 -data=./data
```

启动后访问 `http://127.0.0.1:19081/`。监听地址只允许数值回环地址；未传 `-addr` 时默认使用 `127.0.0.1:19081`。也可通过 `PORT` 指定端口，例如 `PORT=19120 go run ./cmd/pdconsole` 会监听 `127.0.0.1:19120`。

`-data` 指定本地证据目录。服务在其中保存带 `schemaVersion` 的 `snapshot.json` 和只追加的 `audit.log`；启动时会校验冻结边界摘要、证书摘要、审计序号和前序哈希，发现证据链不连续时拒绝启动。

## 标准测试与自检

```text
go test ./...
go run ./cmd/pdconsole -selfcheck -addr=127.0.0.1:19081
```

`-selfcheck` 会在临时数据目录启动真实 HTTP 服务，通过与浏览器相同的 JSON API 完成建批、冻结、正常读数采集、诊断就绪与报告、证据快照双人复核、证书签发、核验包下载和在线完整性核验，然后关闭服务并重新打开证据库验证持久化恢复。该命令执行完成后会主动退出。

## 主要流程

1. 输入电缆区段和回路实时查询未封存批次及最近封存批次；确认重复风险后可独立建批，也可只复用历史批次的区段、回路和负责人。
2. 增删、排序多个试验点，预检全部字段和冲突，核对规范排序后的范围摘要再不可逆冻结。
3. 一次录入多个初始采样或 `retest` 读数；服务端同时检查编号、轮次、冻结点、量程、时间和环境，全部通过后只推进一次版本。
4. 查看逐点诊断就绪清单，再运行幅值、趋势、重复性、环境条件和相位集中规则；报告保留阈值、实际值、证据编号、中文说明和风险汇总，相同证据不会重复运行。
5. 为偏差登记整改后自动生成复验任务包，按规则要求关联足量且晚于整改时间的复验读数，仅在对应规则不再触发时关闭偏差。
6. 所有门禁通过后生成复核证据快照，由两名不同人员针对同一摘要分别提交并锁定意见；任一否决都会阻止签发。
7. 完整性检查通过后签发证书，查看按点归组的证据清单，下载稳定核验包，并在线分别核验证书载荷、证据清单和审计关联。

接口写操作要求 `idempotencyKey`、`expectedVersion` 和 `actor`。发生版本冲突时，API 返回 `409` 及当前版本，页面会刷新批次后提示重新提交。

批量与门禁接口沿用同一主流程：`POST /api/batches/{batchID}/freeze/preflight` 执行冻结预检，`POST /api/batches/{batchID}/measurements/batch` 原子保存读数，`GET /api/batches/{batchID}/diagnosis-readiness` 和 `GET /api/batches/{batchID}/review-readiness` 返回就绪清单。封存后可通过 `GET /api/batches/{batchID}/verification-package` 下载核验包，并通过其 `/verify` 子路径在线复算。
